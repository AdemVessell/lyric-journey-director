# Examples: the places of two finished films

- **`basic-diamond-thoughts-places/`:** the original journey, whose movement,
  direction and effects Adem asked to carry over.
- **`made-well-places/`:** the first film in the house style with heavy grit.
  `mwkit.js` holds its shared parts.

These are for reading, not for reuse. Each place is tied to its own film's line
ids and times, and each film needs its own world. `references/worked-examples.md`
says what each file teaches, and how to run one in a scratch copy.

Both sets use the engine in `template/journey/src/`. Their kit is the template's
`zones/kit.js`.
